# A Triple Shy

A website built around a simple concept: one theme, three hits.

- **Single** — a blog post
- **Double** — a photograph
- **Home Run** — a song

Each edition groups these three pieces of media around a shared theme.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Adding content

Edit `src/app/page.tsx` to update the current theme and the titles/excerpts for each hit.

Then fill in the actual content in:
- `src/app/single/page.tsx` — your blog post
- `src/app/double/page.tsx` — your photograph
- `src/app/home-run/page.tsx` — your song

## Stack

- [Next.js](https://nextjs.org) (App Router)
- [Tailwind CSS](https://tailwindcss.com)
- TypeScript
